# week 4

🚀 Lab Overview
This repository contains practical red team labs designed to simulate real-world adversary tactics, techniques, and procedures (TTPs) in a controlled environment. Each lab focuses on different aspects of modern offensive security operations.

📋 Lab Exercises
1. Advanced C2 Infrastructure
Tools: Cobalt Strike, PoshC2, Metasploit

Tasks: C2 server setup, session management, payload customization

Objectives: Establish HTTPS beacons, manage implants, generate stageless payloads

2. Cloud Attack Simulation
Tools: Pacu, awscli, CloudGoat

Tasks: Cloud enumeration, privilege escalation, data exfiltration

Objectives: Identify misconfigured S3 buckets, exploit IAM weaknesses, extract data

3. Adversary Emulation
Tools: Caldera, Metasploit, Evilginx2

Tasks: APT29 campaign simulation, phishing, persistence

Objectives: Emulate advanced threat actors, test detection capabilities

4. Advanced Evasion Techniques
Tools: msfvenom, Veil, proxychains

Tasks: Payload obfuscation, AV bypass, network evasion

Objectives: Create undetectable payloads, route traffic through Tor

5. Cloud Privilege Abuse
Tools: Pacu, awscli, ScoutSuite

Tasks: Service principal exploitation, cross-tenant attacks

Objectives: Abuse overprivileged roles, escalate to admin

6. Automated Attack Orchestration
Tools: Caldera, Red Team Automation (RTA)

Tasks: Multi-phase attack automation

Objectives: Chain phishing to exploitation, automate RCE

7. Living-Off-the-Land
Tools: PowerShell, WMI, Mimikatz

Tasks: Fileless execution, credential harvesting

Objectives: Use native tools, bypass AV, harvest credentials

8. Professional Reporting
Tools: Google Docs, Draw.io

Tasks: PTES-compliant reports, executive briefings

Objectives: Document findings, create visualizations, communicate risk

9. Capstone: Full Adversary Simulation
Tools: Kali Linux, Metasploit, Caldera, Pacu

Tasks: End-to-end campaign, detection analysis, reporting

Objectives: Simulate full attack lifecycle, test blue team detection

🛠️ Prerequisites
Virtualization software (VMware, VirtualBox)

Kali Linux VM

Windows 10/11 VM (for targets)

AWS Account (for cloud labs)

Cobalt Strike License (for C2 labs)

Basic knowledge of penetration testing and red teaming
